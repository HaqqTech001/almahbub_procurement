# Phase 3 - Trust Experience Blueprint

**Brand:** Almahbub International  
**Platform:** Powered by HAQQ TECH  
**Mission:** A trust framework that immediately builds confidence  
**Deliverable:** Trust strategy · Visual placement · Responsive · Motion. No React.

---

## 1. Trust Strategy

Credibility compounds in a fixed order:

```text
Who we are (Company Story)
  → Who stands with us (Partners)
  → What we can prove (Certifications, Statistics, Reach, Network)
  → What we delivered (Case Studies, Testimonials)
  → How we protect you (Security, Compliance, Response Time)
  → Request Procurement
```

### Principles

| Principle | Meaning |
| --- | --- |
| Evidence over claims | Source, date, limitation - or it does not ship |
| Trust is a path | Each module answers one question, then leads forward |
| Quiet strength | Calm verification - not badge spam or hero overlays |
| One job per module | Aligns with attention laws (docs/51) |
| HAQQ TECH | Quiet platform attribution - never louder than Almahbub |

### Immediate confidence (first seconds)

On Home, trust must appear as a **quiet strip** under the hero CTA - process accountability, Nigeria-rooted partner, verifiable quotes/tracking - **not** floating badges on the hero image.

## 2. Trust elements

| Element | Why it exists | How it increases credibility | How it should be displayed |
| --- | --- | --- | --- |
| **Company Story** | Humanize accountable ownership | Turns vendor into partner with history | About: full narrative + timeline. Home: short strip after partners - not before identity |
| **Certifications** | Prove standards adherence | Third-party validation reduces risk | Named chips + issuer + validity; link to real evidence when available |
| **Partner Logos** | Show ecosystem without false endorsement | Familiar marks transfer cautious confidence | Named logo grid + relationship line; no marquee; no fake “as seen in” |
| **Statistics** | Communicate scale honestly | Sourced numbers quantify capacity | 3–4 metrics: value + label + methodology link; **never count-up** |
| **Case Studies** | Show outcomes under constraints | Specificity beats slogans | Challenge → approach → outcome → constraint; consent required |
| **Client Testimonials** | Peer social proof | Human voice corroborates process | Quote + name + role + org; optional portrait; **no autoplay** |
| **Global Reach** | Ground international capability | Corridors feel operational | Country/corridor list + honest coverage; map optional, never sole info |
| **Supplier Network** | Explain governed supply | Clarifies managed model vs marketplace | Qualification/fit narrative; Partner apply gated; no fake headcount |
| **Response Time** | Set service expectations | Predictability = reliability | Published ranges with caveats (“typically…”); no fictional SLA |
| **Security** | Protect data & access | Enterprise buyers need control signals | Plain-language practices + Privacy/Security links; no fake badge walls |
| **Compliance** | Privacy, trade, policy posture | Reduces regulatory anxiety | Legal links + claimable topics only; evidence when asserted |

## 3. Visual Placement

| Surface | Place | Rule |
| --- | --- | --- |
| Home - hero | Trust strip (text) | Below CTAs/quick entry - **not** on media |
| Home - early | Partner logos | After hero; before heavy capability |
| Home - mid | Stats (if sourced) → services/process | Never before “who we are” |
| Home - lower | Cases → testimonials → FAQ → Request band | Proof then convert |
| About | Full story + certs + compliance | Deep trust destination |
| Services / Procurement / Sourcing | Response time + process + relevant certs | Model trust |
| Supplier Network | Governance + partner marks | Ecosystem trust |
| Catalog / Product | Certs, origin, manufacturer | Evidence trust |
| Contact / Request | Response-time + privacy note | Commitment trust |
| Footer | Security · Privacy · Terms · HAQQ TECH | Always-on assurance |

**Hierarchy:** Identity and Request remain stronger than any trust module. Trust supports conversion; it does not replace the primary CTA.

## 4. Responsive Behaviour

| Element | Behavior |
| --- | --- |
| Partner logos | 5–6 → 3 → 2 columns; no forced horizontal scroll |
| Statistics | 4 → 2 → 1; source under each metric |
| Case studies | 2–3 → 1; full outcome visible without hover |
| Testimonials | One featured quote on mobile; manual controls if multi |
| Global reach | List-first on mobile; map optional on desktop |
| Certifications | Wrapping chips; “+N more” to detail |
| Security / Compliance | Stacked definition lists on small screens |

Touch targets ≥44px for “Read case”, cert links, and legal destinations.

---

## 5. Motion Behaviour

| Moment | Rule |
| --- | --- |
| Default | Trust is mostly **static** - calm beats animation |
| Logos / images | Lazy fade 120–180ms after decode only |
| Cases / quotes | Optional one-time ≤180ms opacity; **no grid stagger** |
| Statistics | **Never** count-up |
| Map / reach | No looping routes, vehicles, or globe spin |
| Carousels | No autoplay; manual only if multi |
| Reduced motion | Instant state; fades optional/off |

Aligns with Motion Design System: explain, never distract.

---

## 6. Ship / Block gates

**Ship only if**

- Statistic has source/methodology  
- Testimonial/case has consent  
- Certification has issuer identity  
- Partner relationship is accurately described  

**Block**

- Vanity counters and guarantee copy  
- Hero badge overlays and marquees  
- Open supplier marketplace framing  
- Security theater without practices/links
